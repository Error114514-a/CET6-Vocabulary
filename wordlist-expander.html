三种输入格式

格式1：完整格式（推荐）

用 | 分隔 6 个字段：单词|音标|释义|英文例句|中文例句|Emoji

格式2：仅单词（自动补全）

每行一个单词，工具自动补全音标占位、释义占位、默认例句、默认 Emoji。适合先录入单词后续再补例句。

补全结果示例：{word:"abandon",phonetic:"",meaning:"",example:"He abandoned.",exampleCn:"",emoji:"📝"}

格式3：单词+释义（推荐快速录入）

用 | 分隔 2 个字段，自动补全例句和 Emoji（按释义关键词匹配）

如何合并到主应用

1. 用本工具生成 JSON 数组

2. 打开 cet-vocab.html，找到 var WORD_LIST = [...]

3. 将生成的 JSON 追加到数组末尾（注意逗号）

4. 保存即可，无需修改其他代码
